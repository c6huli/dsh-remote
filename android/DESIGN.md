# 界面设计语言(雾蓝玻璃)

DSH Remote 1.5.107 起换了一套界面:**雾蓝玻璃(Mist Glass)**。设计语言参考
[`ccch1mneyyy/dsh-Go`](https://github.com/ccch1mneyyy/dsh-Go) 的主题层(配色推导、玻璃材质、
连续圆角、动效 token),按 Compose 重写,并按本 App 的屏幕结构落地。

---

## 一、三条铁律

1. **层次靠材质,不靠阴影。** 页面是一条极淡的竖向渐变;浮在内容上的(顶栏、输入条、
   弹层)是玻璃;躺在页面上的(卡片、胶囊)是半透明白。elevation 一律 0,
   `surfaceTint` 透明。唯一的投影在玻璃**外沿**,且很淡。
2. **细线是骨架。** 卡片、Chip、输入框、对话框都有 0.5–1dp 的线。它比阴影安静,
   在浅色雾蓝底上又比纯色块清楚。
3. **连续圆角。** 全部走五档 + 胶囊,不手写半径。

比例:70% 中性面(渐变 + 玻璃)、25% 文字与细线、≤5% 强调色。强调色只出现在
主按钮、发送键、选中态、链接、进度 —— 铺多了就不"静"了。

---

## 二、配色:OKLCH 推导

所有颜色在 [OKLCH](https://bottosson.github.io/posts/oklab/) 空间里构造。OKLab 的明度是
感知均匀的:同一个 L 在任何色相上看起来一样亮。所以"只换色相、不动明度"就能让
六套配色落在同一档对比度上,文字可读性不用一套一套去调。

| 配色 | 色相 | 彩度 | 中性色倾向 |
|---|---|---|---|
| 雾蓝(默认) | 267° | 0.125 | 雾蓝纸面 |
| 黛青 | 238° | 0.085 | 偏青的雾 |
| 暮紫 | 300° | 0.075 | 藕荷灰 |
| 松石 | 186° | 0.068 | 一点青绿 |
| 琥珀 | 70° | 0.082 | 米白纸 |
| 石墨 | 262° | ~0 | 纯中性灰 |

强调色的各角色按固定明度推导(seed 0.53 / container 0.93 / bubble 0.918 …),
深色主色再提 0.234。用户自定义颜色时走 `AppAccent.derive`,并用 `guard()` 沿明度
挪到"强调色对页面 ≥ 3:1、其上文字 ≥ 4.5:1"为止。

**深色不是纯黑**:明度 0.23–0.25,与 Claude 深色同一档。纯黑底上的亮字长时间看会"晕"。

## 三、玻璃:没有 BackdropFilter 的做法

Compose 没有 iOS 那种"模糊背后的内容"。这里换个等价做法:

- 这个 App 的背景是**同一张渐变 + 两团光**,没有高频细节,对背景做高斯模糊几乎什么都
  不会变;
- 于是 chrome / sheet 两层直接在玻璃形状里**重画一遍背景**(按它在窗口里的位置对齐),
  再叠半透明填充 —— 背后的滚动内容被"换成了背景",读起来就是一块磨砂玻璃,而且不用
  每帧做高斯模糊;
- card / pill 背后只是静态渐变,半透明填充已经足够,不再取样。

关掉透明效果(设置里的「玻璃透明」,或低端机省电)时全部走 `fallbackFill`:
**必须接近不透明**,否则没有取样也没有模糊,背后的内容会透上来把字搅花 —— 这条有测试守着。

阴影用 even-odd 裁剪,**只画在形状外部**:玻璃内部半透明,普通阴影会透过玻璃、又被填充
盖一次,玻璃中间就发灰。

## 四、形状与间距

| 档 | 半径 | 用途 |
|---|---|---|
| xs | 6 | 行内代码、角标、进度条端头 |
| sm | 10 | Chip、工具图标块、小按钮、会话行高亮 |
| md | 14 | 卡片、代码底、输入框、菜单、主按钮 |
| lg | 20 | 用户气泡、审批卡、设置分组卡 |
| xl | 28 | 输入条、底部弹层、对话框、抽屉外侧 |
| pill | — | 顶栏胶囊、模型胶囊、发送键 |

间距以 4 的倍数为主;页面左右留白 16,卡片内边距 14–16,换轮间距 24。

## 五、动效:安静、短、跟手

| 场景 | 时长 |
|---|---|
| 按压反馈 | 90ms 按下 / 200ms 回弹 |
| 淡入淡出、图标切换 | 160ms |
| 小块展开收起、列表进出 | 240ms |
| 思考块 / 工具行折叠 | 280ms |
| 胶囊变形、抽屉落位 | 340ms |
| 弹层进出 | 380 / 260ms |
| 环境呼吸(运行中状态点) | 2400ms 一个周期 |

曲线用 M3 standard(`cubic-bezier(.4,0,.2,1)`)族,进场 `LinearOutSlowIn`、退场
`FastOutLinearIn`、滑行 `cubic-bezier(.32,.72,0,1)`。

系统开启"移除动画"时所有时长归 0,循环动画停在静止帧 —— 不是"变快",是**不动**。

## 六、字体

**系统无衬线负责一切文字,等宽只给代码。**

不打包中文字体:思源黑体单字重 10–20MB,APK 已经背着 Shizuku 等依赖;而且国产 ROM
(MIUI/HyperOS、ColorOS、OriginOS、HarmonyOS)把系统字体换成了 MiSans、OPPO Sans、
vivo Sans、HarmonyOS Sans,质量都很好,跟着系统走最协调。

字重只用 400 / 600 两档:AOSP 只带 Noto Sans CJK Regular 一个字重,w500 会被就近映射回
Regular,w600 才走合成加粗。所以层级只靠字号 + 颜色。

---

## 七、代码高亮的浅色陷阱

原来那套语法高亮色是 One Dark(只适合深色底):`#98C379` 这种绿在浅色代码井
`#EDF0F6` 上只有 1.8:1,根本看不清。现在浅深各一套,由代码井的亮度选择,每一种
高亮色对井底都 ≥ 4.5:1。

---

## 八、测试守着什么

`ThemeContrastTest`(14 个用例)把这些契约写成了断言,换配色 / 调明度时立刻会红:

- 六套配色 × 浅深:正文、次级、三级文字对各级面色 ≥ 4.5;
- 强调色上的文字 ≥ 4.5,容器上的 ≥ 7;
- 强调色对页面 ≥ 3(看得见);
- 用户气泡上的字 ≥ 4.5;
- 中性色换色相后明度漂移 < 0.02(所以"换配色不改对比度"是真的);
- 自定义色推导必须过 guard;
- 玻璃兜底填充 alpha ≥ 0.6(关掉透明后不透字);
- 状态色 / 代码井 ANSI / 工具类别色 / 身份色全部 ≥ 4.5;
- OKLCH 往返误差 < 2/255。

跑法:

```
gradle :app:testReleaseUnitTest
```
