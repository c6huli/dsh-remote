DSH Remote 安卓端版本记录
========================================

说明
- 1.5.31 之前无逐版记录，按已知情况归纳；1.5.32 起逐版如实记录。
- 每版一行：加了什么 / 修了什么 / 去掉了什么。


早期（无逐版记录）
----------------------------------------
0.1.x 期   旧协议 App，点号方法名（session.list），靠主机 3084 桥翻译到 0.2.x。
1.5.3x 期  改为自签名（ef071c7a…），此后所有版本可直接覆盖升级。

此前陆续具备：工作区/会话列表、聊天与工具卡、小鲸鱼动画与运行时长、轨迹页、

1.5.81–1.5.88　收尾
----------------------------------------
1.5.81  改：模型选择器默认折叠、按提供方分组（含插件 provider）。
1.5.82  修：主题切换同步宿主（system 解析为 light/dark），侧边栏与 Web 设置跟随。
1.5.83  改：下载完成清进度通知，另发带声音的完成通知，点击进 App。
1.5.84  改：下载完成通知点击直达「已下载文件」页。
1.5.85  改：隐藏宿主侧空会话（blank），修「新建会话 · 98e8」莫名出现。
1.5.86  修：完成通知真正替换（原字符串替换未生效，进度不清且无声）。
1.5.87  修：审查 5 个 bug —— 新建会话被误隐藏、通知残留、
            去重过宽、模型同流失效、未装插件时白建 WebView。
1.5.88  修：成品卡片重复（去重从「每轮重置」改回「全局按路径」）。
1.5.89  主机侧修复（不含 APK）：桥 session.list 瘦身 + gzip、cookie 401 重签、
            Caddy 压缩、8443 站点名修正。
1.5.90  修：设置 / 侧边栏打不开 —— 插件探测不再缓存 false（原来一次失败就永久
            显示「未安装插件」），面板加载失败改为显示错误码 + 重试。
1.5.91  修：设置面板不再经本地代理（127.0.0.1:3086）—— 那个 localhost 中转会把
            正常的主机变成「加载超时（60 秒）」，而聊天（OkHttp 长连接）却照常。
            改为 WebView 直连主机 + 用注入 JS 做面板裁剪；插件探测同上。
1.5.92  修：设置 → 模型 报「settings are unavailable in this browser」。dsh 的 Web
            客户端只按 location.hostname 判断是否本机，非回环就关掉设置能力；
            新增 127.0.0.1 TCP 隧道（LoopbackTunnel），两个面板都从回环地址加载，
            顺带解决 1.5.91 直连导致的能力缺失 —— 隧道是裸 TCP，WebSocket 也能过。
1.5.93  改：每轮强制出文件卡片，不再依赖 agent 调用 present —— 卡片收集
            present 的 files、diff 卡路径、以及 write/edit/apply_patch 等写文件工具的
            path 参数；去重改为「轮内」，跨轮重复修改会重新列出；标题「产物」，
            超过 8 行折叠为 +N。历史会话打开时同样会补出卡片。
1.5.94  回：面板加载回退到直连主机（1.5.91 的做法）—— 回环隧道在主机侧看到
            55 条 127.0.0.1:3080 请求全 200，但手机上面板空白；隧道代码保留
            在 WEB_PANELS_VIA_LOOPBACK 开关后面，默认关闭。代价：设置→模型
            仍会显示 settings are unavailable（dsh 只对本机回环开放设置能力）。
1.5.95  改：工具结果卡片按类型上色，配色直接取宿主 Web 端的 design token
            （--dsw-static-green-500 / --dsh-file-type-violet / blue-500 /
            deepseek-450 / amber-500 / blue-400 / neutral-bluish-300）：
            终端=绿、写入/产物=紫、读取检索=蓝、网络=深蓝、任务/智能体=琥珀、
            图像=浅蓝、其它=中性；出错始终走红（red-600）。折起的工具组取组内
            占比最高的类型着色，标题图标同色。
1.5.96  改：每轮的产物卡片拆成「最终产物」和「已编辑文件」两段 —— 前者是
            present 交出的东西（默认展开），后者是本轮写过的其它文件（默认折叠，
            点标题展开）；同一路径若既被改过又被 present，只算最终产物。
1.5.97  修：侧边栏 / 设置面板空白 —— 每次装新版自动清一次 WebView 缓存（面板资源
            带 immutable 缓存一年，升级后旧缓存会让页面白屏而网络全 200）；
            设置面板加「清缓存」按钮，侧边栏错误块加「清缓存重载」。
1.5.98  回：按用户要求回到 GitHub 首个发布版（1.5.88）的连接/面板逻辑，只保留卡片
            三项改动 —— 连接探测、设置面板走本地代理 3086、侧边栏直连、插件探测
            缓存等全部与 1.5.88 字节一致（LoopbackTunnel 已删除）。
            卡片：每轮强制出产物卡（不依赖 present）、按类型上色（取 Web 端 token）、
            拆「最终产物 / 已编辑文件」且已编辑默认折叠。
1.5.99  修：1.5.88 的设置面板经本地代理取的是未压缩字节（强制 identity），而客户端
            插件包压缩后就有 4.4MB 单包、几 MB 起步 —— 中继链路上永远加载不完；
            改为 WebView 直连主机（保留 gzip）+ 注入面板裁剪 JS，其余仍与 1.5.88 一致。
1.5.100 修：设置/侧边栏每次打开都停在宿主的「预览版说明」弹窗 —— 注入脚本现在先
            点掉这类一次性提示（继续/知道了/确定…），确认设置弹窗/工作台已出现再停。
